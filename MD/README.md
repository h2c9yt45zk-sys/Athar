# Athar (أثر) - Documentation & Database Schema

## Project Overview
Athar is an Egyptian luxury heritage e-commerce platform offering premium hand-crafted garments, abayas, kaftans, and accessories for women, men, and Islamic collections.

## Architecture
- **Frontend Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Material Symbols + Google Fonts
- **State Management**: React Context API (`CartContext`)
- **Backend / DB Integration**: Supabase Client Integration ready (`src/app/lib/supabase.js`)
